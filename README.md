# Storyphy Engine

Automated personalized alphabet book generator for kids.

## Setup

1. Clone the repo:
```bash
   git clone https://github.com/arvind-555/storyphy_engine_v3.git
   cd storyphy_engine
```

2. Create virtual environment:
```bash
   python -m venv venv
   venv\Scripts\activate
```

3. Install dependencies:
```bash
   pip install -r requirements.txt
```
